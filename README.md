# Site da Clínica Odontológica

Site institucional responsivo, feito com Astro. Mostra as funcionalidades do aplicativo e direciona interessados ao WhatsApp de suporte. Não contém códigos de licença, dados de pacientes ou API de ativação.

## Executar

```sh
npm install
npm run dev
```

## Publicar na Vercel

Importe este diretório como projeto Astro. A Vercel executa `npm run build` e publica a pasta `dist`. O arquivo `vercel.json` inclui cabeçalhos de segurança. As imagens em `public/assets` são demonstrações com dados fictícios.
